# Cursor Jiggler

A lightweight Java Swing utility that periodically moves the mouse cursor.

## Features

- Simple desktop interface
- Configurable movement interval from 5 seconds to 5 minutes
- `OFF` option to pause cursor movement

## Requirements

- Java JDK
- Desktop environment with GUI support

## Run

Open the project in an IDE such as IntelliJ IDEA and run `CursorJiggler.java`. Ensure the `assets/CJ.png` resource is included in the classpath.

## Build

The repository does not currently include a build script. To create a distributable JAR, configure a Java build (such as Maven or Gradle) and package the icon resource with the application.
